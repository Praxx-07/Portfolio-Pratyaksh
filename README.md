# Pratyaksh Danidharia — Portfolio

A responsive single-page portfolio built with Next.js, TypeScript, and Tailwind CSS.
Profile details, skills, and project cards are maintained in `data/portfolio.ts`.

## Run locally

1. Install Node.js 20.9 or newer.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000).

Create and verify a production build with:

```bash
npm run build
npm start
```

## Deploy to Vercel

Import this repository in [Vercel](https://vercel.com/new), keep the detected
Next.js framework settings, and deploy. Vercel builds the site with `npm run
build`; no environment variables are required.
